# ping_pong
## Le dépôt contient un prototype du jeu Ping-Pong. Il s'agit d'un jeu multijoueur...
# mode de fonctionnement
## Le jeu a été implémenté en Python en utilisant la bibliothèque Pygame...
# jouabilité
## Le joueur 1 contrôle la palette gauche à l'aide des touches... Le joueur 2 contrôle la pagaie droite à l'aide des touches...
